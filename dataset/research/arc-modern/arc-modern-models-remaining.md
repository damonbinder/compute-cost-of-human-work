# Model assumptions for the remaining ARC configurations

## deep-think

The native endpoint is `gemini-3-deep-think-preview`, with November 2025 evaluation timestamps. Google's [December 4, 2025 announcement](https://blog.google/products-and-platforms/products/gemini/gemini-3-deep-think/) supplies the first public mode date and describes parallel reasoning. The evaluation preview predates this public release; continuity of the precise revision is not established. This is not the later Gemini 3.1 Deep Think update.

No active parameter count or internal mixture of models is disclosed. Use the dataset's shared 100-billion-active-parameter Gemini Pro-scale prior, or 200 billion FLOPs per processed token. This is a coarse architectural assumption, not a size inferred from the token totals or benchmark score. The original announcement places the mode above Gemini 3 Pro and emphasizes inference-time parallel reasoning, supporting a frontier backbone rather than a small standalone model; it does not establish 100B numerically. The explicit donor chain is the [Gemini 3 Pro prior](../metr/metr-expanded-models.md#gemini-3-pro): [Epoch's original GPT-5 analysis](https://epochai.substack.com/p/notes-on-gpt-5-training-compute) estimates roughly 100B active from serving/pricing context, while [Unexcitedneurons' Opus 4.6 estimate](https://unexcitedneurons.substack.com/p/estimating-the-size-of-claude-opus) derives approximately 100B from 93–105 GB weights/token under FP8. Transferring those contemporary frontier-model scales to Gemini Pro and then Deep Think is weak cross-model evidence; neither source estimates Deep Think directly. Parameter scenarios 25B, 50B, 200B and 400B multiply central compute by 0.25, 0.5, 2 and 4. They are sensitivity scenarios, not confidence bounds.

Apply the coefficient once to the source's aggregate input/output tokens. Native totals already include substantial internal work. The component models and cache reads are not separately exported; applying one backbone coefficient to all aggregate positions is an additional assumption. Research/arc-modern-remaining.md retains the source cross-check and cache scenarios.

## grok-420

The exact native endpoint is `grok-4.20-beta-0309b-reasoning`. The [xAI release notes](https://docs.x.ai/developers/release-notes) date public Grok 4.20 API availability to March 10, 2026, separately from the multi-agent endpoint. Public documentation names `0309`, not the evaluation suffix `0309b`; the date identifies first public family availability, not a verified release date for that exact revision. Retain the native ID rather than silently aliasing it.

Use 115B active parameters (230B FLOPs/token), the consistent coarse Grok-family prior. Neither the 4.20 source records nor xAI's release notes disclose its architecture or active size. The numerical donor is the released Grok-2 architecture, not a size invented for Grok 4.20. Its [original pinned config](https://huggingface.co/xai-org/grok-2/blob/daf4395a80ad177386cfe39641b64fc12b1d70ed/config.json) specifies 64 layers, width 8192, eight experts with two active, intermediate width 16384, and an always-active residual MLP of width 32768. The [released inference implementation](https://github.com/sgl-project/sglang/blob/97a38ee85ba62e268bde6388f1bf8edfe2ca9d76/python/sglang/srt/models/grok.py) executes both the dense MLP and selected experts. Original tensor-header reconstruction gives 63,357,067,264 shared plus 51,539,607,552 selected expert weights = 114,896,674,816 active, rounded to 115B; retained original headers and replay are documented in [the Grok-2 source reconstruction](../epoch/epoch-grok-gpt45-models.md#grok2). Applying this to 4.20 is an explicit weak cross-generation transfer, not evidence that 4.20 preserves that architecture. Scenarios 25B, 78.5B, 200B and 400B scale compute by their ratio to 115B. No additional multi-agent branch multiplier is applied to this single reasoning endpoint.

## gpt-52

The native ID is `gpt-5.2-2025-12-11`, effort `xhigh`; evaluation timestamps precede public release. Reuse the existing registry record unchanged: first public date December 11, 2025 and the shared assumed 100B active / 200B FLOPs-token coefficient. Native data confirms the endpoint and effort, not the parameter count. Its original model evidence is published in research/epoch/epoch-native-families.md. No model-size update is proposed here. Explicit reasoning tokens are already within completion tokens.
